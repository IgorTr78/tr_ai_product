# Igor Treyner — AI Product Manager

Готовый статический сайт для публикации на GitHub и Railway.

## Что внутри
- `index.html` — главная страница
- `preview.png` — Open Graph preview для шаринга
- `favicon-32.png`, `favicon-192.png`, `favicon.ico` — иконки сайта
- `.gitignore` — базовый ignore

## Быстрый запуск локально
Открой `index.html` в браузере.

## Загрузка на GitHub
1. Создай новый репозиторий на GitHub.
2. Залей содержимое этой папки в корень репозитория.
3. Убедись, что файл называется именно `index.html`.

## Деплой на Railway
1. В Railway нажми **New Project**.
2. Выбери **Deploy from GitHub repo**.
3. Подключи репозиторий.
4. Включи public domain в Networking.

## Что проверить перед публикацией
- mobile: 390px
- tablet: 768px
- laptop: 1024px
- desktop: 1440px
- wide: 1920px
